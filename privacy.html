プライバシーポリシー

Hermes Nana Secretary（以下「本アプリ」）は、開発者本人専用の個人用 AI 秘書の Google 連携です。

利用するデータ

本アプリは、開発者本人が許可した範囲で、本人の Gmail（メールの閲覧・整理・下書き・送信）と Google カレンダー（予定の閲覧・作成・変更）にアクセスします。

利用目的

本人の依頼に応じて、メールや予定の確認・整理・返信案の作成を行うためだけに使います。広告、販売、AI モデルの学習には使いません。

保存と共有

認証情報は本人の Mac 内にのみ保存されます。取得したデータを第三者に販売・提供・共有することはありません。

Google API Services User Data Policy

本アプリによる Google API から受け取った情報の利用と他アプリへの転送は、限定使用要件を含む Google API Services User Data Policy に従います。

アクセスの取り消し

アクセス権は Google アカウントのサードパーティ アクセス設定 からいつでも取り消せます。
